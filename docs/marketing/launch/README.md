# Assets de lancement — offre -50% (50 premiers organisateurs)

Assets de la campagne de lancement TournArena, produits par Kelto Studio.
Même argument central que le Reel en préparation (`videos/tournarena-zero-latence/`) :
les classements se mettent à jour en direct, sans rafraîchissement.

- `tournarena-launch-poster.png` — affiche 2160×2700 (4:5), identité "Ink & Signal"
  (thème sombre) de TournArena, crédit Kelto Studio en pied de page.
- `tournarena-launch-poster.html` — source HTML/CSS de l'affiche (rendue en PNG via
  Playwright/Chromium headless à 1080×1350 CSS px, `deviceScaleFactor: 2`). Rouvrir
  et modifier ce fichier pour ajuster le texte/la mise en page, puis re-rendre.
